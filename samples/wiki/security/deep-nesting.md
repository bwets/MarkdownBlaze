# Deep Nesting

**You are not meant to be able to read this page.** The viewer's Markdown parser follows nesting to 128 levels
and then gives up on the document, and the document is replaced by one sentence: *This document is nested too
deeply to display.* If that sentence is what you see, the page did what it should. If you can read these
paragraphs, the limit did not apply — and the page would have been 1,200 quotations deep.

It is the same limit that protects the parser's own recursion, and it is reported as a fact about the document
and not as a fault: nothing is written to the log as an error.
